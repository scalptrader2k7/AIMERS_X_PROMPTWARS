# Safety

MedLens organizes information for review; it does not diagnose, provide treatment or medication advice, alter dosage, estimate risk, or provide emergency guidance.

Laboratory status is computed only from a numeric range explicitly printed in the supplied report. Missing or unusable ranges remain **Not assessed**. A verified label records a user review action, not clinical accuracy.

The demo is for synthetic information only. The pasted report text remains available only in the active browser session for source review. It is sent to MedLens’s processing route for validation and optional AI processing, but is not stored in browser localStorage, included in exports, uploaded as a file, or retained by MedLens as a permanent clinical record. If live processing is unavailable or malformed, MedLens returns a clearly marked deterministic synthetic fallback record and does not claim its values were extracted from the entered text.

Normalization preserves the original source label and only maps a small declared alias list. Conflict flags do not determine which source is correct. Clarification questions identify missing record context; they are not medical advice. MedLens does not use external clinical ranges or medical-knowledge databases.
